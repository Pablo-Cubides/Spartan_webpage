# Content Style Guide

## Tone
- Direct
- Practical
- Clear
- Goal oriented

## Article Structure
1. Hook
2. Problem
3. Why it matters
4. Solution
5. Steps
6. CTA

## SEO Rules
- One clear topic per article
- One unique slug
- Concise meta description
- Internal links where relevant

## Images
- Use relevant cover images
- Prefer optimized assets
- Add descriptive alt text
