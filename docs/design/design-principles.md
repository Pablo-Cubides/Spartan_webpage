# Design Principles

- Spartan, clean, and disciplined visual language
- Mobile-first layouts
- High contrast and readable typography
- Consistent spacing and elevation
- Accessible interactions by default
- Minimal visual noise

## Visual Direction
- Base background: dark neutral surfaces
- Primary accent: Spartan red / deep crimson
- Support accent: bronze or gold for highlights
- Semantic colors: success, warning, error, info

## Rules
- Use tokens, not random colors
- Use reusable components
- Keep state feedback explicit
- Treat content hierarchy as a visual priority
