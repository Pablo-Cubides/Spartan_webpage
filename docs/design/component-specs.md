# Component Specs

## Button
- Variants: primary, secondary, ghost, destructive
- States: default, hover, focus, active, disabled, loading

## Input
- Label always visible
- Error message always actionable
- Focus ring always visible

## Card
- Header, content, optional footer
- Clear hierarchy and spacing

## Modal
- Keyboard dismissible
- Focus trapped
- Has title and action text

## Article Editor
- Title, slug, excerpt, cover image, content, publish actions
- Upload + URL fallback for cover image

## Media Picker
- Preview, upload, validation message, and canonical URL output
