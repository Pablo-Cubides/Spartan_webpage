# Accessibility Spec

- Target WCAG 2.2 AA
- Every interactive control needs a visible focus state
- Every image needs alt text or a documented decorative role
- Every form field needs a label
- Color contrast must remain readable on dark backgrounds
- Keyboard navigation must work for editor and admin flows

## Checks
- Tab through the page
- Verify focus order
- Verify error messages are announced clearly
- Verify buttons and links have clear names
