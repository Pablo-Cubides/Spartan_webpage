# Spartan Club Constitution

## Principles
- Specs are the source of truth.
- Design is part of the spec.
- Content and images must be validated.
- Security checks are mandatory.
- Documentation must stay current.
- Every feature needs examples, not vague intentions.

## Non-Negotiables
- Do not introduce secrets.
- Do not merge undocumented behavior changes.
- Do not bypass validation gates.
- Do not create a second editorial source of truth without a spec decision.

## Definition of Done
- Spec written
- Plan written
- Tasks defined
- Tests and checks passing
- Docs updated
- Rollback path known
