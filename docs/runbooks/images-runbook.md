# Images Runbook

## Upload
1. Select the file
2. Validate size and format
3. Upload through the admin media route
4. Save the canonical URL

## Standards
- JPEG, PNG, WEBP
- Keep files under 10 MB
- Use descriptive names
- Add alt text

## Troubleshooting
- If upload fails, verify auth and file type
- If the URL is broken, check storage config and allowed hosts
